GitHub Actions .IPA Build Guide

Overview

This guide walks you through wrapping this Launcher project into a native iOS app standard package (.ipa) using Capacitor and GitHub Actions (macOS runner). Once generated, you can side-load it via AltStore, SideStore, or TrollStore.

1 Project Structure Setup

Create a repository on GitHub containing your launcher code formatted like this:

my-ios-launcher/
├── www/
│   └── index.html      # (This launcher HTML file)
├── package.json
└── .github/
    └── workflows/
        └── build-ipa.yml

2 Create package.json

Include standard Capacitor iOS dependencies:

{
  "name": "ios-html-launcher",
  "version": "1.0.0",
  "scripts": {
    "build": "npx cap sync"
  },
  "dependencies": {
    "@capacitor/core": "^5.0.0",
    "@capacitor/ios": "^5.0.0"
  },
  "devDependencies": {
    "@capacitor/cli": "^5.0.0"
  }
}

3 GitHub Actions Workflow (build-ipa.yml)

Create .github/workflows/build-ipa.yml to build an un-signed/sideloadable `.ipa` payload automatically on GitHub:

name: Build iOS IPA

on:
  push:
    branches: [ main ]
  workflow_dispatch:

jobs:
  build-ios:
    runs-on: macos-13
    steps:
      - name: Checkout Code
        uses: actions/checkout@v3

      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: 18

      - name: Install Dependencies
        run: npm install

      - name: Initialize Capacitor iOS
        run: |
          npx cap init "HTML Launcher" "com.launcher.htmlapp" --web-dir "www"
          npx cap add ios

      - name: Sync Capacitor
        run: npx cap sync ios

      - name: Build Xcode Archive & Package IPA
        run: |
          cd ios/App
          xcodebuild -workspace App.xcworkspace -scheme App -sdk iphoneos -configuration Release archive -archivePath build/App.xcarchive CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO
          
          mkdir -p build/Payload
          cp -r build/App.xcarchive/Products/Applications/App.app build/Payload/
          cd build && zip -r HTML_Launcher.ipa Payload

      - name: Upload IPA Artifact
        uses: actions/upload-artifact@v3
        with:
          name: HTML-Launcher-IPA
          path: ios/App/build/HTML_Launcher.ipa

Installing on your iPhone

  1. Download HTML_Launcher.ipa from GitHub Actions Artifacts.
  2. Sideload via AltStore, SideStore, Scarlet, or TrollStore.
  3. Open the app on your iOS device to import and launch 9 custom micro apps with native speed!
